# ✨ Project Overview

**NPA Risk AI – Predictive Intelligence** is an AI-powered banking analytics platform developed to predict the risk of **Non-Performing Assets (NPA)** using Machine Learning algorithms and predictive analytics techniques.

The system helps banks and financial institutions identify high-risk borrowers before loan defaults occur, enabling proactive risk management and smarter lending decisions.

---

# 🎯 Objectives

✅ Predict loan default probability
✅ Identify high-risk borrowers
✅ Reduce Non-Performing Assets (NPAs)
✅ Improve banking risk assessment
✅ Enable intelligent lending decisions
✅ Support real-time banking analytics

---

# 🧠 Machine Learning Algorithms Used

| Algorithm                       | Purpose             |
| ------------------------------- | ------------------- |
| 🌲 Random Forest                | Risk Prediction     |
| 📈 Logistic Regression          | Credit Scoring      |
| ⚡ Gradient Boosting             | Ensemble Prediction |
| 🧠 Support Vector Machine (SVM) | Classification      |
| 🔥 Decision Trees               | Risk Analysis       |

The project compares multiple ML models to identify the most accurate predictive solution for banking risk assessment.
